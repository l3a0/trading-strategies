# ruff/pyright release adds rules that flag previously-clean code and breaks
# CI with no code change (ruff 0.16.0 did exactly this on 2026-07-23 —
# EXE001/RUF046 on files untouched for months). Bump these deliberately,
# clearing the new findings in the same commit, rather than have a linter
# release fail an unrelated PR. numpy/pandas/etc. don't have this failure
# mode, so they stay unpinned.
#

# fix. Ruff 0.16.0 expanded its defaults from 59 rules to 413, so the 0.16.x
# bump raised 337 findings here with no code change. The repo's standard is
# written down now, so a ruff release can change its defaults without changing
# ours. Widening the rule set is a separate, deliberate change.
